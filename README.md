Recommendation System for Job Finding using Natural Language Processing Techniques



###### **How to install through GitHub/วิธีติดตั้งผ่าน GitHub**



**Requirements to install/สิ่งที่จำเป็นต่อการติดตั้ง**

1\.ติดตั้ง vscode และ Git

2\.ติดตั้ง Visual Studio Code

3\.ติดตั้ง Python 3.8+ ใน Visual Studio Code

4\.ติดตั้ง Jupyter Extension สำหรับ VS Code

5.VS Code + Jupyter Extension for VS Code

6\.ติดตั้ง git ผ่านลิงค์ https://git-scm.com/downloads/win



**Install through GitHub/ขั้นตอนการติดตั้ง**

1.Clone โปรเจกต์จาก GitHub

1.1.กดปุ่มสีเขียวในหน้า Github โปรเจคผมแล้วกดคัดลอกลิงค์บน Clone using web URL

1.2เปิด Visual Studio Code

1.3Ctrl+Shift+P จากนั้นพิมพ์ "Git: Clone" กด enter

1.4Ctrl+V เพื่อ paste ลิงค์ clone แล้วกด enter

1.5เลือก directory ที่จะติดตั้งโปรเจคนี้ แล้วกด enter

2\.ติดตั้ง dependencies (ดูทั้งหมดใน requirements.txt)เช่น pandas, numpy, scikit-learn, sentence-transformers, tqdm, etc.

2.1เปิด terminal โดยไปที่ขีด 3 ขีดซ้ายบนของ vscode> Terminal> New Terminal

2.2จากนั้น Run "pip install -r requirements.txt"
